# UGF.GameFramework.Data 配表数据类型规则方案

> 本文档定义 Excel 配表 → 二进制数据表 → DataRow 代码生成全链路的数据类型规则。
> 标注为「已实现」的能力当前可用；标注为「方案」的为规划能力，实现后自动生效。

---

## 1. 概述

配表数据类型体系按三个层次组织：

```
基础类型 (8种) → 枚举 → 集合类型 (数组/List/HashSet/Dictionary) → 嵌套集合 (任意深度)
```

- **Excel 第 2 行**声明字段类型，类型以字符串形式写在单元格内。
- **集合字段的值使用 JSON 字面量书写**（`[...]`、`{...}`），嵌套即 JSON 嵌套，任意深度，语法是通用标准，配表人员零自定义规则负担。
- **非集合标量字段保持原样书写**（`1001`、`铁剑`、`true`），与既有表完全兼容。
- **类型判定**统一由 `SupportedDataTypes` 提供（含集合类型注册表）。
- **二进制存储**由 BinaryDataSerializer/Deserializer 递归读写，格式自描述（字段类型字符串写在文件头），因此新增类型无需升级版本号。
- **运行时读取**由 DataRowCodeGenerator 生成静态类型化的 `ParseDataRow(byte[])` 代码。

---

## 2. Excel 表格式规范

```
第1行：字段名称
第2行：字段类型（本方案的核心）
第3行：字段描述（可选）
第4行起：数据行，每行一条记录
```

| 行 | 内容 |
|----|------|
| 1 | `Id` \| `Skills` \| `Tags` \| `Bonus` |
| 2 | `int` \| `int[]` \| `List<string>` \| `Dictionary<string,int>` |
| 3 | 主键 \| 技能ID列表 \| 标签列表 \| 属性加成 |
| 4 | `1001` \| `[1001,1002]` \| `["攻击","防御"]` \| `{"atk":100,"def":50}` |

- 第一列默认为主键，建议使用 `int` 或 `long`。
- 字段名为空则跳过该列；类型为空则回退为 `string`（带警告）。
- 数据行为空单元格 = 该字段取默认值（见第 10 节）。

## 3. 类型体系总览

| 类别 | 类型写法 | 示例 |
|------|----------|------|
| 基础类型 | `int` `long` `float` `double` `bool` `string` `byte` `short` | `int` |
| 枚举 | `enum:枚举名` 或直接写枚举名 | `enum:ItemType` / `ItemType` |
| 引用类型 | `@表名`，底层按目标表主键类型存储 | `@Drop`、`List<@Drop>`、`Dictionary<@Drop,int>` |
| 数组 | `T[]`，T 为基础/枚举/集合 | `int[]` `string[]` `int[][]` `List<int>[]` |
| 列表 | `List<T>`，T 为任意支持类型 | `List<int>` `List<enum:ItemType>` `List<List<int>>` |
| 哈希集 | `HashSet<T>`，T 为任意支持类型 | `HashSet<int>` `HashSet<enum:ItemType>` |
| 字典 | `Dictionary<K,V>`，K/V 为任意支持类型 | `Dictionary<string,int>` `Dictionary<int,List<string>>` |
| 自定义类 | 类型定义表 Classes 中定义的类型 | `ItemData` `List<ItemData>` |
| 自定义结构体 | 类型定义表 Structs 中定义的类型 | `ItemStack` `List<ItemStack>` |

> 集合元素/键值类型均支持基础类型、枚举、**引用类型（@表名）**、自定义类/结构体以及**再嵌套的集合**（任意深度，第 7 节）。引用类型详见 [数据表关系字段方案](数据表关系字段方案.md)。

## 4. 基础类型（已实现）

| 类型 | C# 类型 | 取值范围 | 单元格写法示例 | 二进制读取 | 默认值 |
|------|---------|----------|----------------|-----------|--------|
| `int` | `int` | -2,147,483,648 ~ 2,147,483,647 | `1001` | ReadInt32 | 0 |
| `long` | `long` | -9.22e18 ~ 9.22e18 | `9223372036854775807` | ReadInt64 | 0L |
| `float` | `float` | ±3.4e38 | `100.5` | ReadSingle | 0f |
| `double` | `double` | ±1.7e308 | `100.5` | ReadDouble | 0.0 |
| `bool` | `bool` | `true/false/1/0` | `true` `1` | ReadBoolean | false |
| `string` | `string` | 任意字符串 | `铁剑` | ReadString | 空串 |
| `byte` | `byte` | 0 ~ 255 | `200` | ReadByte | 0 |
| `short` | `short` | -32,768 ~ 32,767 | `12000` | ReadInt16 | 0 |

要点：
- `bool` 接受 `true/false`、`1/0`（`1/0` 经 `Convert.ToBoolean` 转换）。
- 数值解析使用当前区域性的 `Parse`，建议统一写标准十进制。
- `float/double` 支持科学计数法字符串（`1e3`）经 `Parse` 解析。
- 超出取值范围的数值会转换失败，该单元格回退为默认值并输出错误日志。
- 标量字段**不做 JSON 要求**：`string` 直接写文本（不加引号），`int` 直接写数字。

## 5. 枚举类型（已实现）

### 5.1 声明方式

| 写法 | 说明 |
|------|------|
| `enum:ItemType` | 显式前缀，推荐 |
| `ItemType` | 直接写枚举类型名（非基础、非集合的类型名自动判定为枚举） |

### 5.2 单元格写法

- 标量枚举字段：数字下标 `1` 或枚举名 `Weapon`（解析期尝试反射 `Enum.TryParse`）。
- 集合内枚举元素（JSON 内）：数字 `1` 或带引号名字 `"Weapon"`（JSON 字符串，解析期按枚举名转换）。

### 5.3 存储

枚举在二进制中一律按 **int** 存储（`ReadInt32`/`Write(Int32)`），读取时强转为枚举类型。

---

## 6. 集合类型（单层）

集合字段的值用 **JSON 字面量**书写。单层即 JSON 数组 / JSON 对象。

### 6.1 数组 `T[]`、列表 `List<T>`、哈希集 `HashSet<T>`

写法一致：`[元素1, 元素2, ...]`（JSON 数组）。

| 字段名 | Type | 数据单元格 |
|--------|------|-----------|
| SkillIds | `int[]` | `[1001,1002,1003]` |
| Tags | `List<string>` | `["攻击","防御"]` |
| Areas | `HashSet<int>` | `[1,2,3]` |

生成属性：`public int[] SkillIds { get; private set; }` 等。
- `HashSet` 元素自动去重，重复值只保留一个。
- 数字元素可裸写（`1`），字符串元素必须带双引号（`"攻击"`），枚举元素可数字或带引号名字。

### 6.2 字典 `Dictionary<K,V>`

写法：`{"键":值, "键2":值2}`（JSON 对象）。

| 字段名 | Type | 数据单元格 |
|--------|------|-----------|
| Bonus | `Dictionary<string,int>` | `{"atk":100,"def":50}` |

- string 键必须带双引号；int/long 等数字键可裸写（`{1:"a",2:"b"}`）。
- 键重复时后者覆盖前者。
- 生成属性：`public Dictionary<string,int> Bonus { get; private set; }`

### 6.3 单层集合元素类型支持

元素/键值类型支持全部基础类型与枚举：`int/long/float/double/bool/string/byte/short` 及 `enum:类型`。

---

## 7. 嵌套集合（方案）

### 7.1 JSON 嵌套规则（核心规则）

集合字段值整体是一个 JSON 字面量，**嵌套即 JSON 嵌套**：

- 数组/List/HashSet → `[ ... ]`，元素间 `,` 分隔
- 字典 → `{ "键":值, ... }`，键值间 `:` 分隔
- 集合元素本身是集合 → 递归写 `[ ... ]` / `{ ... }`，任意深度
- 空集合：空数组 `[]`；空字典 `{}`
- 允许空白（空格/Tab/换行）美化排版

示例对照：

| 类型 | 单元格写法 |
|------|-----------|
| `List<int>` | `[1,2,3]` |
| `List<List<int>>` | `[[1,2],[3,4]]` |
| `List<List<List<int>>>` | `[[[1,2],[3]],[[4],[5,6]]]` |
| `int[][]` | `[[1,2],[3,4]]` |
| `Dictionary<string,List<int>>` | `{"a":[1,2],"b":[3,4]}` |
| `Dictionary<int,List<List<int>>>` | `{1:[[1,2],[3]],2:[[4],[5,6]]}` |
| `List<Dictionary<string,int>>` | `[{"a":1,"b":2},{"c":3,"d":4}]` |
| `List<Dictionary<string,List<int>>>` | `[{"a":[1,2],"b":[3,4]},{"c":[5,6],"d":[7,8]}]` |
| `Dictionary<string,int[]>` | `{"atk":[1,2],"def":[3,4]}` |
| `Dictionary<List<int>,string>` | `{[1,2]:"a",[3,4]:"b"}`（键为集合，按引用相等语义） |
| `List<enum:ItemType>` | `[1,2]` 或 `["Weapon","Armor"]` |
| `List<List<string>>` | `[["攻击|1","防御|2"],["火","水"]]`（`|` 无需转义，普通字符） |

### 7.2 解析语义

- 递归下降解析 JSON 字面量：`[` → 数组/列表；`{` → 字典。
- 字符串元素：以 `"` 开头，`\"`/`\\` 转义，引号不闭合视为解析失败。
- 数字/枚举元素：裸 token，先按数字尝试，失败按枚举名（仅元素类型为枚举时）。
- 空元素/悬空逗号（`[1,,2]`、`[,1]`）→ 解析失败，回退默认值并报错。
- 结构不完整（括号不配平、缺 `:`）→ 解析失败，回退默认值并报错。

## 8. 语法与转义规则

### 8.1 JSON 语法一览

| 符号 | 含义 |
|------|------|
| `[` `]` | 数组/List/HashSet 包裹 |
| `{` `}` | 字典包裹 |
| `,` | 元素分隔 / 键值对分隔 |
| `:` | 字典键值分隔 |
| `"` | 字符串包裹 |
| `\` | 字符串内转义前缀 |

### 8.2 字符串转义

字符串元素/键必须用双引号包裹，内部按 JSON 转义规则：

| 转义写法 | 还原结果 |
|----------|----------|
| `\"` | `"`（双引号） |
| `\\` | `\`（反斜杠） |
| 其他字符 | 原样保留（`\/` 也可写为 `/`） |

示例：

| 单元格 | 类型 | 还原值 |
|--------|------|--------|
| `["攻击","防御"]` | `List<string>` | `["攻击","防御"]` |
| `["a\"b"]` | `List<string>` | `["a\"b"]` |
| `["C:\\temp"]` | `List<string>` | `["C:\temp"]` |
| `{"atk":100,"def":50}` | `Dictionary<string,int>` | `{"atk":100,"def":50}` |
| `{"a,b":1}` | `Dictionary<string,int>` | `{"a,b":1}`（逗号在引号内，无需转义） |

> 数字/枚举/布尔元素裸写，**不存在自定义分隔符，因此 `|`、`;` 等字符在字符串内完全自由**（普通字符），这是相比分隔符方案的最大简化。

## 9. 类型判定规则（优先级）

对第 2 行的类型字符串，按以下顺序判定（第一个命中生效）：

```
1. 基础类型        IsSupported          → int/long/float/double/bool/string/byte/short
2. 数组            EndsWith("[]")       → 去掉末尾 [] 后递归判定元素类型
3. 注册表集合       前缀 + <...>         → List / HashSet / Dictionary（注册表可扩展）
4. 引用类型        StartsWith("@")      → @表名，底层按目标表主键类型存储（需构建期注册）
5. 自定义类型      查自定义类型注册表     → Classes/Structs 中定义的类型（需配置类型定义文件）
6. 枚举            enum:前缀 或 非基础非集合非引用类型名
7. 其他            回退为 string（警告）
```

- `List<int>` 不会被误判为枚举（先判定集合）。
- `@Drop` 不会被误判为枚举（引用判定先于枚举宽松规则）。
- 配置了类型定义文件时，`ItemStack` 若命中注册表 → 按结构体/类处理，不再落入枚举分支。
- 未配置类型定义文件时，`ItemStack` 等未知类型名仍按宽松规则视为枚举（向后兼容）。
- 集合元素/键值类型提取统一走「泛型括号深度匹配」：`Dictionary<K,V>` 按**顶层逗号**切分（`<`/`>` 深度为 0 时的逗号），因此 `Dictionary<List<int>,string>` 中 `List<int>` 内部的逗号不会误切。
- `int[]`、`int[][]`、`List<int>[]` 均识别为数组，元素类型递归解析。

## 10. 默认值与空值

| 情况 | 结果 |
|------|------|
| 空单元格 + 基础类型 | 默认值（0 / 0f / 0L / 0.0 / false / 空串 / 0 / 0） |
| 空单元格 + 枚举 | 0 |
| 空单元格 + 集合类型 | 空集合（count = 0），**不存在 null** |
| 单元格写 `[]` / `{}` | 空集合 |
| 字典键值缺值 | 解析失败，回退默认值并报错 |

> 二进制中没有 null 概念：集合空 = count 0；基础类型空 = 默认值。这与运行时 `IDataRow` 的无参构造一致。

## 11. 二进制序列化格式

### 11.1 文件头

```
魔数(4字节, 0x44544247 "GBTD") | 版本(1字节, 当前=1) | 表名(string)
| 字段数(int) | 每个字段: 名(string) 类型(string) 描述(string) 是否主键(bool)
| 记录数(int)
```

### 11.2 字段值（递归）

| 类型 | 布局 |
|------|------|
| 基础类型 | 定长二进制原语（见第 4 节） |
| 枚举 | int32 |
| 数组/List/HashSet | `count(int32)` + 依次每个元素 |
| 字典 | `count(int32)` + 依次每对 `key, value` |
| 嵌套集合 | 递归应用上述规则 |

示例：`List<List<int>>` = `[[1,2],[3,4]]` →
```
count=2
  count=2  1  2
  count=2  3  4
```

- 字段类型字符串已写在文件头，读取端按类型递归解码，**无需版本升级即可扩展新类型**。

## 12. DataRow 代码生成规则

### 12.1 属性

- 集合字段属性类型：`int[]` / `List<T>` / `HashSet<T>` / `Dictionary<K,V>`，其中 T/K/V 为递归解析后的完整 C# 类型。
- 枚举字段属性：枚举类型名（如 `ItemType`），值按 int 读取后强转。

### 12.2 ParseDataRow(byte[]) 读取代码

按类型生成读取代码：

| 类型 | 生成代码模式 |
|------|-------------|
| 基础/枚举 | `field = binaryReader.ReadXxx();` 枚举为 `(EnumName)ReadInt32()` |
| List/HashSet | `var count = ReadInt32(); field = new List<T>(count); for(...) field.Add(expr);` |
| 数组 | `var count = ReadInt32(); field = new T[count]; for(...) field[i] = expr;` |
| 字典 | `var count = ReadInt32(); field = new Dictionary<K,V>(count); for(...) field[k] = v;` |
| 嵌套集合 | 递归生成内层读取块（局部变量承接内层集合，循环变量名按深度唯一化） |

### 12.3 递归生成示例（`Dictionary<string,List<int>>`）

```csharp
var count = binaryReader.ReadInt32();
Bonus = new Dictionary<string, List<int>>(count);
for (var i = 0; i < count; i++)
{
    var key = binaryReader.ReadString();
    var value = new List<int>(binaryReader.ReadInt32());
    for (var i0 = 0; i0 < value.Count; i0++)
    {
        value.Add(binaryReader.ReadInt32());
    }
    Bonus[key] = value;
}
```

## 13. 类型注册表与扩展机制（方案）

集合类型的识别、类型名拼接、代码生成模板集中在一张**描述表**中，避免「每新增一种集合就要改多处代码」：

| 注册名 | 泛型参数 | 构造模板 | 添加元素 |
|--------|----------|----------|----------|
| `List` | T | `new List<T>(count)` | `.Add(x)` |
| `HashSet` | T | `new HashSet<T>(count)` | `.Add(x)` |
| `Dictionary` | K,V | `new Dictionary<K,V>(count)` | `[k] = v` |
| 数组 | T | `new T[count]` | `[i] = x` |
| `Queue`（可扩展） | T | `new Queue<T>(count)` | `.Enqueue(x)` |
| `Stack`（可扩展） | T | `new Stack<T>(count)` | `.Push(x)` |
| `LinkedList`（可扩展） | T | `new LinkedList<T>()` | `.AddLast(x)` |

- **新增集合类型 = 注册表加一行**（解析/序列化/反序列化自动生效，因为它们基于 `IEnumerable`/`IDictionary`；代码生成走注册表模板）。
- 解析层按 `IEnumerable` 读取元素、`IDictionary` 读取键值对，与具体集合类无关。
- 元素/键值类型提取统一走「泛型括号深度匹配」，支持任意嵌套。

## 15. 边界情况与限制

| 情况 | 行为 / 限制 |
|------|-------------|
| 空单元格 | 基础类型=默认值，集合=空集合 |
| 主键 | 第一列，建议 int/long，需唯一 |
| 字符串含 `"`/`\` | 按 JSON 转义（`\"` `\\`） |
| 字符串含 `\|` `;` `,` `[]` `{}` | 无需转义（普通字符，仅逗号/括号/引号在 JSON 结构层生效） |
| 元素自动去重 | 仅 `HashSet`；`List`/数组保留重复 |
| 字典键重复 | 后者覆盖前者 |
| JSON 结构不完整 | 解析失败，回退默认值并报错 |
| `HashSet<T>` 嵌套引用类型 | 按引用去重（如 `HashSet<List<int>>`），实际使用需注意语义 |
| 未知类型字符串 | 回退为 `string` 并警告 |
| 类型大小写 | 基础类型不区分大小写（`Int`=合法）；集合前缀 `List`/`HashSet`/`Dictionary` 不区分大小写 |
| 嵌套深度 | JSON 嵌套无理论上限，受 Excel 单元格长度与可读性限制，建议 ≤ 3 层 |
| 序列化版本 | 保持 version=1，类型由文件头的类型字符串描述，向前兼容 |
| 字符串重载 ParseDataRow(string) | 暂未实现（返回 false），仅二进制重载可用 |
| 既有单层表兼容 | 标量字段写法不变；集合字段旧格式 `1\|2` 需改为 `[1,2]` |

## 16. 决策记录

| 决策 | 选择 | 理由 |
|------|------|------|
| 嵌套书写 | JSON 字面量（`[` `{` `,` `:` `"`） | 通用标准、零自定义规则、任意深度无歧义、配表人直觉 |
| ~~交替/符号循环分隔符~~ | ~~`\|`/`;`/`,` 层级分隔~~ | 依赖自定义分隔符 + 转义，书写繁琐易错，已弃用 |
| ~~自定义括号方案~~ | ~~`[a=1\|b=2]`~~ | 手写转义多、易错，已弃用 |
| 标量字段 | 保持原样（`1001`、`铁剑`） | 与既有表兼容，集合字段才用 JSON |
| 字符串转义 | JSON 标准（`\"` `\\`） | 大家熟悉的唯一转义规则 |
| 字典键值分隔 | JSON `:` | 标准 |
| 嵌套深度 | JSON 任意深度递归 | 一个方案覆盖所有情况 |
| 类型扩展 | 注册表驱动 | 新增集合类型只加一行，解析/序列化/反序列化零改动 |
| 枚举存储 | int | 与既有实现一致，二进制紧凑 |
| 空集合 | count=0 | 二进制无 null，与运行时行为一致 |

## 18. 自定义类/结构体类型（方案）

数据表字段除基础类型、枚举、集合外，还支持引用**类型定义表**（TypeDefinitions.xlsx）中定义的类（Classes 表）与结构体（Structs 表），以及与它们组合的集合/嵌套。

### 18.1 前置条件

- 构建数据表时配置「类型定义文件路径」（可选）。配置后启用自定义类型支持。
- 类型定义文件由现有 TypeDefinitionBuilder 体系解析并生成类/结构体 C# 代码。

### 18.2 类型判定

新增**自定义类型注册表**（类型名 → 枚举/类/结构体定义），判定顺序：

```
基础类型 → 数组 → 注册表集合 → 自定义类/结构体 → 枚举 → string 回退
```

- 配置了类型定义文件：`ItemStack` 命中注册表 → 按结构体处理；未命中 → 宽松枚举规则。
- 未配置：行为与现状一致（未知类型名按枚举，向后兼容）。

### 18.3 Excel 单元格写法（JSON 延续）

自定义类型实例 = JSON 对象，键与成员名大小写不敏感匹配：

| 类型 | 单元格写法 |
|------|-----------|
| `ItemStack`（结构体字段） | `{"itemId":1,"count":5}` |
| `ItemData`（类字段） | `{"id":1001,"name":"铁剑","tags":["攻击","近战"]}` |
| `List<ItemStack>` | `[{"itemId":1,"count":5},{"itemId":2,"count":3}]` |
| `Dictionary<int,ItemStack>` | `{1:{"itemId":1,"count":5},2:{"itemId":2,"count":3}}` |
| `List<List<ItemStack>>` | `[[{"itemId":1}],[{"itemId":2},{"itemId":3}]]` |
| 嵌套自定义（成员为自定义类型） | `{"pos":{"x":1,"y":2},"stack":{"itemId":3,"count":1}}` |

- 缺省的成员：用类型定义中的 DefaultValue；无默认值则用类型默认值。
- 成员本身支持：基础类型、枚举、数组（IsArray）、集合、以及**其他自定义类型**（递归）。

### 18.4 二进制序列化格式

自定义类型实例 = **按成员定义顺序**递归写入（与第 11 节规则同构）：

```
ItemStack { ItemId:int, Count:int } = {1, 5}
→ 写入: int32(1) int32(5)

List<ItemStack> = [{1,5},{2,3}]
→ 写入: int32(2) int32(1) int32(5) int32(2) int32(3)
```

- 文件头字段类型字符串已含类型名；**成员元数据不内嵌**，运行时由生成的 DataRow 代码按定义读取。
- BinaryDataViewer 解析自定义类型时需传入类型定义元数据（可选）。

### 18.5 DataRow 代码生成

对自定义类型字段生成 `new` + 逐成员读取代码：

```csharp
// 直接字段 ItemStack
var temp = new ItemStack();
temp.ItemId = binaryReader.ReadInt32();
temp.Count = binaryReader.ReadInt32();
Stack = temp;

// List<ItemStack>
var count = binaryReader.ReadInt32();
Stacks = new List<ItemStack>(count);
for (var i = 0; i < count; i++)
{
    var e = new ItemStack();
    e.ItemId = binaryReader.ReadInt32();
    e.Count = binaryReader.ReadInt32();
    Stacks.Add(e);
}
```

- 类/结构体需有无参构造（结构体由生成器保证；类默认有无参构造）。
- 成员读取按类型分发：基础定长 / 枚举 `(Enum)ReadInt32()` / 数组与集合 `count+循环` / 嵌套自定义递归。
- 循环变量与临时变量名按深度唯一化，避免冲突。

### 18.6 限制

| 情况 | 行为 |
|------|------|
| 类继承（BaseClass 非空） | 不支持，构建时警告并忽略基类成员 |
| 循环引用（A 含 B、B 含 A） | 检测并报错 |
| 嵌套深度 | 建议 ≤ 3，受单元格可读性限制 |
| 未配置类型定义文件 | 自定义类型名按宽松枚举规则处理（向后兼容） |
